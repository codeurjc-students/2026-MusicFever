How it works

Create a Room

The host creates a private room and becomes responsible for playback

Share the Code

Guests join from their own devices using the room code or the QR code

Add Songs

Everyone searches for music and adds songs to the shared queue

Host Plays

Music from the shared queue plays on the host device

View Stats

After the room ends, review what was played and your room activity

warning

Spotify Premium required

To create a room, the host must have a linked Spotify Premium account. You can link your account from your profile settings or when creating a room.

This is also required for all registered users that wants to listen to music (individually) on the Music Fever app.
